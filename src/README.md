# ⚔️ Java Arena

Java의 기초 문법부터 객체지향 개념까지 직접 구현하며 복습하기 위한 콘솔 기반 RPG 전투 프로젝트입니다.

완성 자체보다는 **배운 Java 개념을 직접 설계하고 구현할 수 있는지 확인하는 것**을 목표로 합니다.

# 📋 구현 요구사항

## 1. 진영

모든 유닛은 다음 두 진영 중 하나에 속한다.

- `RED`
- `BLUE`

진영은 `enum`을 사용하여 구현한다.

---

## 2. Unit

모든 전투 유닛이 공통으로 가지는 정보를 정의한다.

### 필드

- 이름
- HP
- 최대 HP
- 공격력
- 진영

### 공통 행동

- 공격
- 피해 받기
- 현재 상태 출력
- 생존 여부 확인

필드는 가능한 한 외부에서 직접 변경할 수 없도록 캡슐화한다.

---

## 3. 직업

최소 3개의 직업을 구현한다.

### ⚔️ Swordsman

- HP: `600`
- 기본 공격력: `50`
- 특수 능력: 강 공격
- 기본 공격보다 높은 피해를 입힌다.

### 🏹 Archer

- HP: `450`
- 기본 공격력: `60`
- 특수 능력: 치명타 공격
- 특정 조건에서 공격력이 2배가 된다.

### 🧙 Wizard

- HP: `350`
- 기본 공격력: `80`
- 특수 능력: 파이어볼
- 기본 공격보다 높은 피해를 입힌다.

공통 기능은 상위 클래스로 분리하고 필요한 기능은 오버라이딩한다.

---

## 4. 공격 시스템

유닛은 다른 유닛을 공격할 수 있다.

공격 시 상대방의 HP가 공격력만큼 감소한다.

HP는 `0`보다 작아질 수 없다.

예시:

```text
병준이 Orc에게 50의 피해를 입혔습니다.

Orc HP: 650 / 700
```

---

## 5. 아군 공격 방지

공격자와 대상의 진영이 같다면 공격할 수 없다.

```text
RED → RED ❌
BLUE → BLUE ❌

RED → BLUE ✅
BLUE → RED ✅
```

같은 진영을 공격하면 다음과 같은 메시지를 출력한다.

```text
같은 진영은 공격할 수 없습니다.
```

---

## 6. Monster

몬스터를 최소 2종류 구현한다.

### Slime

- 고유 HP
- 고유 공격력

### Orc

- 고유 HP
- 고유 공격력

몬스터 역시 공격과 피격이 가능해야 한다.

---

## 7. Battle

전투를 담당하는 클래스를 구현한다.

두 전투 대상을 받아 한쪽이 사망할 때까지 전투를 진행한다.

```text
TURN 1

A 공격
↓
B 생존 확인
↓
B 공격
↓
A 생존 확인
↓
TURN 2
↓
...
```

반복문을 활용한다.

---

## 8. 생존 판정

HP에 따라 유닛의 생존 여부를 판단한다.

```text
HP > 0  → 생존
HP == 0 → 사망
```

생존 여부를 반환하는 메서드를 구현한다.

---

## 9. 전투 종료

한쪽 유닛이 사망하면 전투를 종료한다.

```text
===== 전투 종료 =====

승자: 병준
남은 HP: 125
```

---

## 10. HP 상태

현재 HP와 최대 HP의 비율에 따라 상태를 결정한다.

| HP | 상태 |
| --- | --- |
| 70% 이상 | 건강 |
| 30% 이상 ~ 70% 미만 | 부상 |
| 0% 초과 ~ 30% 미만 | 위험 |
| 0 | 사망 |

`if / else if / else`를 활용한다.

---

## 11. 스킬 선택

사용자가 행동을 선택할 수 있도록 구현한다.

```text
1. 기본 공격
2. 특수 공격
3. 상태 확인
```

`switch`를 활용하여 선택한 행동을 처리한다.

---

## 12. Interface

최소 하나 이상의 인터페이스를 직접 설계하여 사용한다.

어떤 역할을 인터페이스로 분리할지는 구현 과정에서 직접 결정한다.

---

## 13. Abstract Class

공통적인 유닛 구조를 표현하기 위해 최소 하나 이상의 추상 클래스를 사용한다.

어떤 클래스를 추상화할지는 직접 결정한다.

---

## 14. instanceof

실제로 객체 타입을 확인해야 하는 상황을 만들고 `instanceof`를 활용한다.

단순히 요구사항을 만족시키기 위한 의미 없는 사용은 피한다.

---

## 15. Object 메서드 오버라이딩

최소 하나의 클래스에서 `toString()`을 오버라이딩한다.

유닛 정보를 출력하는 데 활용한다.

---

## 16. 사용자 입력

`Scanner`를 사용하여 사용자가 전투 행동을 선택할 수 있도록 한다.

```text
[병준의 턴]

1. 기본 공격
2. 강 공격
3. 상태 확인

선택 > 2
```

---

## 17. 배열 또는 컬렉션

여러 유닛을 하나의 배열 또는 컬렉션으로 관리한다.

예:

```text
RED TEAM

- Swordsman
- Archer
- Wizard

BLUE TEAM

- Swordsman
- Archer
- Wizard
```

---

## 18. 전체 게임 흐름

최종적으로 다음 흐름으로 프로그램이 동작하도록 구현한다.

```text
게임 데이터 생성
        ↓
캐릭터 생성
        ↓
팀 구성
        ↓
전투 시작
        ↓
사용자 입력
        ↓
공격 / 스킬
        ↓
HP 처리
        ↓
생존 여부 확인
        ↓
승패 판정
        ↓
결과 출력
```

## 19. 예외 상황

다음 상황들을 적절하게 처리한다.

- 존재하지 않는 스킬 번호 입력
- 이미 사망한 대상 공격
- 같은 진영 공격
- HP가 음수가 되는 상황
